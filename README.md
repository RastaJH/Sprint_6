# Sprint_6 - UI тесты для Яндекс.Самокат

## Структура проекта
- data.py - тестовые данные
- locators/ - локаторы элементов
- pages/ - Page Object модели
- tests/ - тестовые сценарии
- allure_results/ - результаты тестов для Allure отчетов

## Установка зависимостей
pip install -r requirements.txt

## Запуск тестов
pytest

## Тестовые сценарии
1. Проверка FAQ - ответы на 8 вопросов (параметризованный тест)
2. Оформление заказа через обе кнопки с разными данными
3. Проверка навигации по логотипам
